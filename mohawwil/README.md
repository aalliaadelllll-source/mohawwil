## ✨ المميزات

| | |
|---|---|
| ⚡ **الإرسال المباشر** | أرسل أي ملف بدون قوائم، والبوت يقترح التحويلات المناسبة له |
| 🧩 **24 أداة تحويل** | صور، PDF، Word، صوت، فيديو، OCR، QR، ZIP |
| 🔤 **عربي كامل (RTL)** | نص ➜ PDF و Word بتشكيل وربط حروف صحيح |
| 🛡 **تكيّف ذكي مع السيرفر** | الأدوات التي ينقصها برنامج على سيرفرك تُخفى تلقائياً بدل أن تسبب أخطاء |
| 📈 **شريط تقدم متحرك** | مع حجم الناتج والوقت والمتبقي من الحد اليومي |
| 🚦 **حماية** | حد يومي، مهلة للتحويل، تحويل واحد لكل مستخدم، حد للتحويلات المتزامنة |
| 📊 **لوحة أدمن** | إحصائيات، أكثر الأدوات استخداماً، الأدوات المعطلة، إذاعة (`/broadcast`) |
| 🔐 **أمان** | لا توكن بالكود، تشغيل Docker بمستخدم عادي، ملفات مؤقتة تُحذف تلقائياً |

## 🧰 التحويلات

| القسم | التحويلات |
|---|---|
| 🖼 الصور | PNG / JPG / WEBP، صور ➜ PDF، ضغط، تصغير الأبعاد (مع تصحيح اتجاه صور الجوال) |
| 📄 PDF | PDF ➜ صور، دمج، تقسيم، ضغط، PDF ➜ TXT، PDF ➜ Word، Word ➜ PDF |
| 📝 النصوص | نص ➜ PDF و Word (عربي) |
| 🎙 الصوت | MP3 / WAV / OGG (يدعم الرسائل الصوتية) |
| 🎬 الفيديو | فيديو ➜ MP3، فيديو ➜ GIF، ضغط الفيديو |
| 🔍 OCR | استخراج نص عربي وإنجليزي من الصور |
| 🧰 أخرى | إنشاء QR، ضغط ZIP |

## 🗂 هيكل المشروع

```
main.py         نقطة التشغيل (فحص التوكن، الأوامر، التنظيف)
app.py          نقطة دخول بديلة لاستضافات تشغّل app.py
handlers.py     القوائم، الإرسال المباشر، التنفيذ، لوحة الأدمن
converters.py   كل التحويلات + سجل الأدوات + فحص الجاهزية
keyboards.py    الأزرار     texts.py   النصوص     db.py   SQLite
config.py       الإعدادات من متغيرات البيئة
check.py        فاحص الجاهزية (أي تحويلات ستعمل على سيرفرك)
tests/          اختبارات سريعة
```

## ⚙️ التشغيل

### المتغيرات

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `BOT_TOKEN` | توكن البوت من @BotFather (**إجباري**) | — |
| `ADMIN_IDS` | أرقام الأدمن، مفصولة بفاصلة | فارغ |
| `DAILY_LIMIT` | تحويلات يومية لكل مستخدم | 30 |
| `MAX_FILE_MB` | أقصى حجم للملف | 20 |
| `MAX_MULTI` | أقصى ملفات في التحويل المتعدد | 20 |
| `MAX_CONCURRENT` | تحويلات متزامنة | 2 |

### 1) تشغيل عادي
```bash
pip install -r requirements.txt
cp .env.example .env        # ضع BOT_TOKEN داخله
python check.py             # يعرض الأدوات الجاهزة على جهازك
python main.py
```
برامج النظام (اختيارية، كل برنامج يفعّل أدوات معينة):
`ffmpeg` (صوت/فيديو) • `tesseract-ocr` + `tesseract-ocr-ara` (OCR) • `libreoffice-writer` (Word ➜ PDF)

### 2) Docker (يثبّت كل شيء تلقائياً — الأفضل)
```bash
cp .env.example .env
docker compose up -d --build
docker compose logs -f
```

### 3) استضافات Python البسيطة (مثل FPS.ms)
ارفع الملفات وضع `BOT_TOKEN` في المتغيرات؛ نقطة التشغيل `app.py` موجودة.
ستعمل أدوات الصور وPDF والنصوص، وأدوات الصوت والفيديو وOCR وWord ➜ PDF تُخفى تلقائياً إن لم تتوفر برامجها.

## 🔤 الخط العربي
لأجمل PDF من النص: ضع `Cairo-Regular.ttf` (من Google Fonts) داخل مجلد `fonts/`.
بدونه يستخدم البوت DejaVu أو Arial.

## 🔐 الأمان
- لا تضع التوكن في الكود ولا ترفع `.env` (محمي بـ `.gitignore`).
- إذا انكشف التوكن: @BotFather ← `/revoke` ← ضع الجديد.

## 🧩 إضافة تحويل جديد
اكتب دالة في `converters.py` ثم أضف سطر `Tool(...)` في قائمة `_T` مع `needs=(...)` للمتطلبات — ويظهر زر تلقائياً.

## 🩺 حل المشاكل
| المشكلة | الحل |
|---|---|
| زر تحويل غير موجود | شغّل `python check.py` وشوف ما ينقص سيرفرك |
| `شكل BOT_TOKEN غير صحيح` | انسخ التوكن كاملاً من @BotFather بدون مسافات |
| البوت لا يرد | تأكد أن نسخة واحدة فقط تعمل بنفس التوكن |
| ملف كبير لا يُقبل | حد تيليجرام للبوتات 20MB للتنزيل و50MB للإرسال |

## 📝 ملاحظات حقيقية
- حفظ الإحصائيات (`data/`) يحتاج تخزيناً دائماً (Volume) على الاستضافات التي تمسح الملفات عند إعادة النشر.
- حد 20MB قيد من تيليجرام؛ لتجاوزه يلزم خادم Bot API محلي.
